# C# Complete Pack

A practical C# learning repository, from language fundamentals to object-oriented programming, collections, LINQ, asynchronous code, and small console projects.

## Requirements

- .NET 8 SDK or newer
- No third-party packages are required

## Run an example

From the repository root:

```bash
dotnet run --project 01_basics/HelloWorld
```

Each example directory is a separate small .NET console project. Build a project with `dotnet build <project-directory>`.

## Contents

- `01_basics/`: hello world, variables, and types
- `02_control_flow/`: conditionals and loops
- `03_methods/`: methods and recursion
- `04_oop/`: classes, inheritance, interfaces, and records
- `05_collections_linq/`: collections and LINQ
- `06_errors_files/`: exceptions and file operations
- `07_async/`: async/await and tasks
- `08_projects/`: calculator and todo-list console projects
